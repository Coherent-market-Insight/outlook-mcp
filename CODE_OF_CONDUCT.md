# Code of Conduct

We want this to be a welcoming project for everyone who takes part.

**Expected:** be respectful and patient, give and take feedback constructively, assume good faith, and focus on what is best for the project and its users.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing other people's private information, and any other conduct that would be inappropriate in a professional setting.

Maintainers may remove comments, commits, issues and contributions that do not follow this code, and may restrict participation for repeated or serious violations.

To report a problem, use GitHub's private reporting (**Security → Report a vulnerability**) or contact a maintainer through their GitHub profile. Reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
